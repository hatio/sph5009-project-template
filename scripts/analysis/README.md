# scripts/analysis/

The "final" statistical analysis and outputs of the project: models,
summary tables, and publication-ready figures.

Anything saved here under `output/` (created automatically when
`analysis.R` runs) is a computed output and is excluded from Git via
`.gitignore`, since it can always be regenerated by re-running the
pipeline against the same data and code.

## Files

- **`analysis.R`** — runs the main statistical analysis on
  `patient_data_clean` and writes results to `scripts/analysis/output/`.
